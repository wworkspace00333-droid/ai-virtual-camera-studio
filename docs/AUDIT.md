## 2. Реализовано, но не проверено полностью

| Возможность | Чего не хватает |

| Расширение камеры «AI Virtual Camera» (CMIOExtension, источник + приёмник) | собирается и встраивается; **не установлено** — нужна подпись платной командой Apple Developer (SIP включён). Доставка кадров независимым клиентам через **это** расширение не проверена; механизм приёмника проверен на расширении OBS |
| Активация `OSSystemExtensionRequest` | код есть; без подписи не запускался |
| Внешние программы: QuickTime, FaceTime, Zoom, Meet (Chrome/Safari), Discord | не проверялись: Zoom и Discord не установлены; FaceTime и Meet требуют входа и звонка; проверен только собственный AVFoundation-клиент |

| Глобальные горячие клавиши при реальном нажатии | регистрация проверена тестом; реальные нажатия — только в «Карточке для игры» через обработчик |

## 4. Ошибки и слабые места

| # | Где | Проблема | Серьёзность |
|---|---|---|---|
| 1 | приложение | **Нет защиты от второго экземпляра.** Две копии одновременно отправляют кадры в одну камеру и мешают друг другу (найдено вживую: калибровка карточки не видела меток) | высокая |
| 2 | `ai/engine.py` | Режим «Авто» выбирает модель по размеру среди **всех** моделей, включая добавленные пользователем с другими классами | высокая (после фазы 4) |
| 3 | `CameraExtension/ExtensionProvider.swift` | Петля чтения приёмника: быстрый stop→start может оставить две петли; после аварийного выхода отправителя петля бесконечно повторяет попытки каждые 20 мс | средняя (не установлено) |
| 4 | `ExtensionProvider.swift` | `activeFormatIndex` / `activeFrameRate` меняются в очереди клиента CMIO, а читаются таймером в очереди устройства — гонка данных | низкая |
| 5 | `native/project.yml` | Версия расширения 0.9.0 не совпадает с версией приложения 0.2.0 | низкая |
| 6 | `ai/engine.py` | Бюджет автовыбора модели не учитывает время распознавания лиц (~9 мс) | низкая |
| 7 | разные файлы | 25 замечаний pyflakes: неиспользуемые импорты/переменные; остаток `if True:` в `video_pipeline.py` | гигиена |

Тихо проглатываемых исключений 10, все оправданы (очистка при закрытии, `__del__`, аварийный обработчик,
подписчики журнала). Заглушек нет: два `NotImplementedError` — методы абстрактного класса источника,
два пустых метода `VideoView` — точки расширения для подклассов.
