# Установка на другой Mac

## Что нужно

- Mac с процессором Apple Silicon (M1, M2, M3, M4, M5). Intel не поддерживается.
- macOS 13 или новее.
- [OBS Studio](https://obsproject.com) 30 или новее.

## 1. Скачать приложение

1. Откройте репозиторий на GitHub (войдите в свой аккаунт: репозиторий приватный).
2. Справа нажмите **Releases** и откройте последнюю версию.
3. Скачайте файл `AI-Virtual-Camera-Studio-<версия>.dmg` (около 205 МБ).

Через терминал, если установлен `gh` и выполнен вход (`gh auth login`):

```bash
gh release download --repo wworkspace00333-droid/ai-virtual-camera-studio --pattern "*.dmg"
```

## 2. Установить

1. Откройте DMG и перетащите **AI Virtual Camera Studio** в папку **Программы**.
2. Первый запуск. Приложение подписано без аккаунта Apple Developer, поэтому macOS его блокирует:
   - в Finder нажмите на приложение **правой кнопкой → Открыть → Открыть**;
   - или: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.

   То же самое одной командой:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/AI Virtual Camera Studio.app"
   ```

3. Проверка, что всё работает на этом Mac (модели, видеокарта, Metal):

   ```bash
   "/Applications/AI Virtual Camera Studio.app/Contents/MacOS/AIVirtualCameraStudio" --self-check
   ```

   Должно быть «OK: 11/12» или 12/12 (ffmpeg необязателен).

## 3. Настроить OBS

1. Запустите OBS. Один раз нажмите **Запустить виртуальную камеру** и разрешите системное расширение,
   если macOS попросит. После этого камеру можно остановить.
2. В приложении откройте **Вход → Установить плагин OBS**, затем перезапустите OBS.
3. В OBS: **Инструменты → AI Virtual Camera Studio: share frames** (включить).
4. Добавьте в сцену OBS источник (камера, экран или видео). Пустая сцена даёт чёрную картинку.

## 4. Запустить

1. В приложении: **Вход → способ «Прямая передача кадров OBS»**.
2. **Виртуальная камера → Отправлять обработанное видео в: OBS Virtual Camera.**
3. Захват запускается сам при открытии (или **Превью → Старт**).
4. В браузере, игре или эмуляторе выберите камеру **OBS Virtual Camera**.

Язык интерфейса: **Настройки → Язык** (применяется после перезапуска).

## Разрешения macOS

| Разрешение | Когда спрашивается | Зачем |
|---|---|---|
| Камера | при захвате с камеры | вход с OBS Virtual Camera или другой камеры |
| Запись экрана | при «Карточка для игры → Найти рамку автоматически» | приложение смотрит, где игра показывает камеру |

Если отказали по ошибке: **Системные настройки → Конфиденциальность и безопасность**.

## Карточка для игры

**Превью → Карточка для игры…**

1. **Карточки:** «Добавить фото…», перетащите файлы в окно или скопируйте картинку и нажмите **⌘V**.
2. Откройте игру с камерой **OBS Virtual Camera** и нажмите **Найти рамки автоматически**
   (приложение скроется на ~4 секунды). Находятся все рамки игры; каждая получает свою карточку.
3. Не та рамка — выберите её в списке **Рамка** и обведите мышкой на снимке. **Новая рамка** — добавить ещё одну.
4. Карточка в игре отражена — включите **Отразить карточку** (для каждой рамки отдельно).
5. **Сохранить рамки как…** — запомнить рамки под названием игры. В следующий раз выберите игру
   в списке **Игра**, и рамки встанут на место без поиска.

**Горячие клавиши** (работают, даже когда открыта игра; ⌘ ⌥):

| Клавиши | Действие |
|---|---|
| ⌘⌥→ | следующая карточка в выбранной рамке |
| ⌘⌥← | предыдущая карточка |
| ⌘⌥C | показать / скрыть все карточки |

Изменить — **Настройки → Горячие клавиши**.

## Запуск из исходников (для разработки)

```bash
git clone https://github.com/wworkspace00333-droid/ai-virtual-camera-studio.git
cd ai-virtual-camera-studio
scripts/setup_dev.sh          # Python 3.12 (Homebrew), зависимости, нативные библиотеки
scripts/run.sh
```

Сборка своего DMG: `scripts/build_app.sh --dmg` (подробности в [PACKAGING.md](PACKAGING.md)).

## Чего пока нет

Своя камера «AI Virtual Camera» и установщик без предупреждения macOS требуют платного аккаунта
Apple Developer. До тех пор видео выходит через OBS Virtual Camera.
